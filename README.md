# AI Life Journey

"A dark-themed, modern AI Life Simulator web application.



Layout:



Left sidebar: Player status bards (Happiness, Wealth, Career, Stress - 0 to 100%).



Main area: Interactive story timeline where an AI acts as a life narrator.



Features:



A starting form to create a character (Age, Occupation, Personality, Ultimate Goal).



The AI generates a life scenario based on the character.



Provide 3 choice buttons for the user, plus an 'AI Recommendation' badge on the best option. Also include a custom text input for custom actions.



When a choice is selected, update the stats with smooth animations and generate the next life event.



Make the UI clean, modern, and engaging with Tailwind CSS and Lucide icons."
